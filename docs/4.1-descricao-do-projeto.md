# 4.1 Descrição do Projeto

## O problema, na voz do cliente

> "Preciso controlar melhor os produtos do meu mercado, saber o que entra e sai e evitar que faltem produtos no estoque." (dono do mercado)

## Propósito

O sistema será utilizado para facilitar o controle dos produtos de um mercado. Atualmente, o controle pode ser feito de forma manual, dificultando o acompanhamento das entradas, saídas e quantidades disponíveis.

## Objetivo

Permitir que o dono do mercado mantenha o estoque atualizado, saiba a quantidade de cada produto disponível e acompanhe a movimentação dos produtos.

## Quem usa

- **Dono do mercado.** Cadastra, consulta, altera e exclui produtos, além de controlar as entradas e saídas do estoque.
- **Funcionário.** Consulta os produtos e registra entradas e saídas de mercadorias.

O cliente é o João, dono do mercado. no sistema ele utiliza o perfil de dono.

## Escopo

- O sistema cadastra produtos.
- O sistema consulta produtos e quantidades em estoque.
- O sistema altera os dados dos produtos.
- O sistema exclui produtos cadastrados.
- O sistema registra entradas e saídas de mercadorias.
- O sistema gera relatórios do estoque.

## Fora do escopo

- Controle de vendas e pagamentos, porque o sistema será focado apenas no controle de estoque.
- Controle de funcionários e salários, porque essas informações não fazem parte do gerenciamento de produtos.

## Características principais

O sistema deverá ser simples e fácil de utilizar, permitindo que o dono e os funcionários realizem as operações de estoque de forma rápida. Os dados dos produtos deverão ser armazenados de forma organizada e protegida, evitando alterações ou exclusões não autorizadas.
